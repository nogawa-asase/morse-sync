# 要求内容

## 概要

作成画面の「1拍の長さ」は変えると分かりにくくなるため、普段は隠し、「オプション」ボタンを押すと開いて出てくる形にする。

## 受け入れ条件

- [ ] 作成画面の初期表示では「1拍の長さ」の入力欄が見えず、「オプション」ボタンだけが表示される
- [ ] 「オプション」を押すと「1拍の長さ」の入力欄が開き、もう一度押すと閉じる
- [ ] 参加画面から戻ったときなど、1拍の長さが既定値(250ms)以外で作成画面を開いた場合は、最初から開いている(設定が隠れて気づけなくならないように)
- [ ] 1拍の長さが範囲外のエラーのときは、閉じていても自動で開く
- [ ] 「オプション」ボタンのタップ領域は44px以上、キーボードでも開閉できる
- [ ] 並び順: メッセージ → 画面の点灯色 → オプション(1拍の長さ) → メッセージの長さ

## スコープ外

- 点灯色をオプションに入れること
