# 要求内容

## 概要

ユーザーからの指摘を受け、作成画面と参加画面の表示・操作を4点改善する。

## 実装対象の機能

### 1. 「1周の長さ」を「メッセージの長さ」に改める(作成画面)
- モールス信号を知らない人には「1周」が分かりにくいため、表示ラベルを「メッセージの長さ」にする(値の計算は変えない)

### 2. URLの表示をやめ、「QRコードの中身」を小さなウインドウで説明する(作成画面)
- QRコードの下のURLの表示を削除する
- 代わりに「QRコードの中身」リンクを置き、押すと画面の上に小さなウインドウ(モーダル)を表示する
- ウインドウには「このQRコードの内容は以下のとおりです。」とURLを表示し、URLの仕組み(`v` はバージョン、など)を、コンピュータに詳しくない人にも分かる言葉で解説する

### 3. 参加前の画面から「1拍の長さ」の表示を削除する(参加画面)

### 4. 一時停止の画面に「パターンの作成に戻る」ボタンを追加する(参加画面)
- 参加後は作成画面に戻る手段がなかったため

## 受け入れ条件

- [ ] 作成画面に「メッセージの長さ: 8.5秒」のように表示され、「1周の長さ」の文言がない
- [ ] 作成画面のQRコードの下にURLの文字列が表示されない
- [ ] 「QRコードの中身」を押すと小さなウインドウが開き、「このQRコードの内容は以下のとおりです。」、URL、各項目(`v` `l` `m` `p` `u` `c`)の値と説明が表示される
- [ ] ウインドウは「閉じる」ボタン・Escキーで閉じられる。ウインドウ内のURLは選択してコピーできる
- [ ] 設定を変えるとウインドウの内容も新しい設定になる(開き直したとき)
- [ ] 共有に失敗したときは「共有できませんでした。「QRコードの中身」からURLをコピーしてください」と表示する(URLの表示をなくしたため)
- [ ] 参加前の画面に1拍の長さが表示されない(メッセージは表示する)
- [ ] 一時停止中に「再開」と「パターンの作成に戻る」が表示され、後者で作成画面に戻り、メッセージ・1拍・色が引き継がれる
- [ ] 作成画面に戻ったとき、Wake Lock・フルスクリーン・カメラ(フラッシュ)が解放される
- [ ] 幅320pxで横スクロールが出ない

## スコープ外

- 参加画面の「QRコードを見せる」画面への「QRコードの中身」の追加
- 「メッセージの長さ」の計算方法の変更(区切り7拍を含む1周分の所要時間のまま)
