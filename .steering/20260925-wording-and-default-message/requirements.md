# 要求内容

## 概要

ユーザーからの指摘を受け、作成画面と「QRコードの中身」の文言、メッセージの長さの表示、既定のメッセージを見直す。

## 実装対象と受け入れ条件

- [ ] 作成画面のラベル「点灯色」を「画面の点灯色」にする(フラッシュは色を変えられないため、画面の色であることを明確にする)
- [ ] 作成画面の「メッセージの長さ」に、URLの `p` と同じ値(秒の整数)を表示する(例: 8.5秒ではなく9秒)。60秒を超える場合も同じ切り上げの値を表示する
- [ ] 「QRコードの中身」の説明を次の文にする: 「#」より前はこのページの住所で、「#」より後ろに点灯パターンの設定が入っています。設定は「記号=値」を「&」でつないだものです。
- [ ] `v` の説明を「このサービスのバージョン」にする
- [ ] `p` の説明を「繰り返しの間隔(秒)」にする
- [ ] `c` の説明から「(先頭の # は省いています)」を削除する
- [ ] 作成画面の既定のメッセージを `SOS` から `NO WAR` にする(15.0秒 → `p=15`)

## スコープ外

- 用語集の表記の統一表の「点灯色」(画面ラベル以外の用語は変えない)
