# 要求内容

## 概要

点滅中のメニューに「早く」「遅く」ボタンを追加し、端末の時計のずれによる開始のずれを、参加者が目で見ながら50msずつ補正できるようにする。

## 背景

- 実機で並べると、端末によって少し早い・遅いがあった。点灯の間隔にずれはなく、開始時刻(端末の時計)のずれと考えられる
- 通信なしで同期する方針のため、ずれを自動で測る手段がない。参加者が手で合わせられるようにする

## 実装対象の機能

- メニューに「◀ 早く」「遅く ▶」「0に戻す」と、今の補正量(例: 「100ms早く」「補正なし」)を表示する
- 1回の補正は50ms、上限は早く・遅くとも1000ms
- 補正は点灯の計算に使う時刻をずらすだけで、点灯の間隔は変えない。画面とフラッシュの両方に効く
- 補正はページを開いている間だけ覚える(端末には保存しない)
  - 覚えたまま: メニューの開閉、QRコード表示→戻る、一時停止→再開、タブ切替・画面オフからの復帰、作成画面に戻って同じパターンで参加し直す
  - 0に戻る: ページの読み込み直し、タブを閉じる、別の点灯パターンで参加する

## 受け入れ条件

- [ ] メニューに「早く」「遅く」「0に戻す」と補正量が表示される
- [ ] 「早く」を1回押すと、点灯・消灯が50ms早くなる(同じ時刻で比べて、補正なしより50ms先の状態になる)
- [ ] 「遅く」はその逆。押すたびに50msずつ変わり、補正量の表示も変わる
- [ ] 1000msに達したら、その方向のボタンは押せなくなる
- [ ] 「0に戻す」で補正なしに戻る
- [ ] QRコード表示→戻る、一時停止→再開、タブ切替から戻っても補正が残る
- [ ] 作成画面に戻って同じパターンで参加し直しても補正が残る。別のパターンでは0から
- [ ] 補正のボタンを押している間は、メニューが自動で閉じない(押すたびに5秒のタイマーをやり直す)
- [ ] ボタンのタップ領域は44px以上、幅320pxで横スクロールしない

## スコープ外

- 補正の端末への保存
- ずれの自動測定
