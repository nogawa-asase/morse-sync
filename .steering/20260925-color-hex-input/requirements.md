# 要求内容

## 概要

作成画面の点灯色を、カラーピッカー(左の四角)と16進の入力欄のどちらからでも設定できるようにし、重複していた色のプレビューを削除する。

## 背景

- 作成画面に、カラーピッカーと同じ色のプレビューの四角が2つ並んでいて、役割が分かりにくい(ユーザーからの指摘)
- 色コード(`#006eff`)を直接入力・貼り付けで設定したい

## 実装対象の機能

### 1. 16進の入力欄
- 色コードの表示を、編集できる入力欄に変える
- 正しい6桁が入った時点で、カラーピッカーの色・QRコードに反映する

### 2. カラーピッカーとの相互反映
- カラーピッカーで選んだ色は入力欄にすぐ反映する

### 3. プレビューの削除
- 右側の色のプレビューを削除する

## 受け入れ条件

- [ ] カラーピッカーで色を選ぶと、入力欄が `#rrggbb`(小文字)に変わり、QRコードが更新される
- [ ] 入力欄に `#006eff` / `006eff` / `#006EFF` のいずれを入れても、カラーピッカーの色が変わり、URLの `c` は `006eff` になる
- [ ] 入力途中など6桁の16進でないときは「点灯色は #ffcc00 のように6桁で入力してください」と表示し、QRコードを隠す
- [ ] 入力欄からフォーカスが外れたとき、正しい値なら `#rrggbb`(小文字)の表記にそろえる
- [ ] 色のプレビューの四角が表示されない
- [ ] 入力欄にラベルが関連付けられ、タップ領域は44px以上

## スコープ外

- 3桁の短縮表記(`#fc0`)や色名(`red`)の入力
- 参加画面の変更
